# Larsen Kids Playroom

Learning games for ages 3 to 18 that work with no internet once installed.

**Play:** https://larsdav.github.io/kids-playroom/

## Install on a tablet or phone
1. Open the address above once while online.
2. iPad or iPhone: Safari, Share button, **Add to Home Screen**.
   Android: Chrome menu, **Add to Home screen** or **Install app**.
3. After that, it opens and plays with no internet.

Players, stars and stickers are saved on each device. This copy does not sync with the copy inside Claude, and family photos are not included.

## Updating
The page is built from the Claude artifact's source. Replace `index.html` and `sw.js` with a new build; devices pick up the new version the next time they open it online.
